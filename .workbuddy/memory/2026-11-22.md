# 2026-11-22 工作日志

## 项目分析 FastGithubPy
- 项目：Python + tkinter + tkwebui 的 GitHub 加速工具箱（非 PyQt），单文件入口 main.py
- 结构：core/（代理、IP 探测、系统代理/自启、服务层）、ui/（主题、控件、主窗口、托盘、5 个页面）
- 单实例锁：绑定 127.0.0.1:38459；托盘用 pystray，独立守护线程，回调经 root.after 派发到主线程

## 实现：最小化到托盘功能
- 原状态：`minimize_to_tray` 配置与设置页开关存在但实际无效——点关闭按钮始终 quit_app() 直接退出；README 与开机自启注册表都传 `--minimized`，但 main.py 从未解析
- 修改文件：
  - `main.py`：解析 `--minimized` 启动参数 → window.hide_to_tray()
  - `ui/main_window.py`：新增 hide_to_tray()（withdraw，托盘不可用则拒绝隐藏）、show_window() 增强（deiconify+lift+focus_force）、_on_unmap/_maybe_hide_on_minimize（点标题栏最小化也收托盘）、_on_close 按配置决定隐藏或退出
- 关键踩坑：Tkinter 无 `<UnmapNotify>` 事件（X11 名），绑定会抛 TclError 导致启动崩溃；正确事件名是 `<Unmap>`。用 root.state() 区分 iconic（用户最小化）与 withdrawn（主动隐藏），避免自触发递归

## 关键：用户运行的是打包 exe，源码改动需重新打包才生效
- 现象：用户截图说看不到新选项；排查发现运行的是 `C:\360极速浏览器X下载\FastGithubPy-windows\FastGithubPy.exe`（旧打包版），不是项目源码
- 该项目有 PyInstaller spec：`FastGithubPy-onefile.spec`（单文件，输出 dist/FastGithubPy.exe）；旧 dist/FastGithub.exe 是另一份旧产物
- 打包环境：Python314 已装 pyinstaller 6.22.3（阿里云源）；命令 `python -m PyInstaller FastGithubPy-onefile.spec --noconfirm`，约 48 秒，产出 22.7MB
- 打包 warning 里的 pwd/grp/fcntl/numpy/olefile 缺失均为 Windows 打包常规误报，可忽略
- 新 exe 产出到 `dist/FastGithubPy.exe`，未替换用户正在用的旧 exe（需用户自己关闭进程后替换）
- 教训：这个项目用户实际用打包 exe 运行，之后每次改源码都要重新打包并提醒用户替换 exe，否则看不到效果
